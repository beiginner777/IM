# IM 系统部署说明

> 本项目支持两种部署方式，**裸机部署**（推荐）和**全容器化部署**。
> 环境要求：Ubuntu 24.04（或 WSL Ubuntu），root 用户。

---

## 一、部署方式总览

| 方式 | C++ 服务跑哪 | 基础设施（MySQL/Redis/Nginx） | 配置文件 | 脚本 |
| --- | --- | --- | --- | --- |
| **裸机部署（推荐）** | 宿主机（本机进程） | Docker 容器 | `config.local.ini` | `deploy.sh` |
| 全容器化 | Docker 容器 | Docker 容器 | `config.ini` | `run.sh` |

两者**配置独立、互不影响**：
- 容器化用各服务目录的 `config.ini`（容器名 + `/app/certs`）
- 裸机用各服务目录的 `config.local.ini`（`127.0.0.1` + 宿主机映射端口 + `docker/certs/`）

---

## 二、裸机部署（推荐）

### 2.1 一键部署

```bash
git clone https://github.com/beiginner777/IM.git
cd IM/linux-server
git checkout feat-baremetal-deploy      # 若 main 已合并可跳过
sh deploy.sh <公网IP>                   # 公网IP加入证书 SAN，客户端公网访问需要
```

`deploy.sh` 自动完成 6 步（幂等，已装/已编译自动跳过）：
装 Docker → 装依赖 → 生成证书 → 起基础设施 → 编译 → 起服务。

### 2.2 手动分步部署

```bash
cd IM/linux-server

# 1. 装 Docker（首次）
sh setup_docker.sh

# 2. 装编译依赖（首次）
sh docker/setup_wsl.sh
apt-get install -y libcrypt-dev        # setup_wsl.sh 漏的依赖

# 3. 生成 TLS 证书
cd docker && bash gen_certs.sh <公网IP> && cd ..

# 4. 起基础设施（MySQL 主从 + Redis 哨兵 + Nginx）
sh docker-start.sh

# 5. 编译
sh build.sh

# 6. 起服务
sh start-all.sh
```

## 三、全容器化部署（备选）

```bash
cd IM/linux-server
sh setup_docker.sh
cd docker && bash gen_certs.sh <公网IP> && cd ..
sh run.sh                               # 构建镜像 + 起所有容器 + 自动配 MySQL 主从
```

## 四、脚本功能清单

| 脚本 | 功能 |
| --- | --- |
| `deploy.sh` | 裸机一键部署入口（编排下面 6 个脚本） |
| `setup_docker.sh` | 装 Docker + 配置镜像加速 |
| `docker/setup_wsl.sh` | 装编译工具链 + 依赖库 |
| `docker/gen_certs.sh [IP]` | 生成自签 CA + 服务器证书 |
| `docker-start.sh` | 起基础设施：MySQL 主从（自动配主从 + 建分片表）+ Redis 哨兵 + Nginx |
| `build.sh` | 生成 protobuf + cmake + make 编译 |
| `start-all.sh` | 启动 6 个 C++ 服务（走 config.local.ini） |
| `run.sh` | 全容器化一键部署（docker-compose） |

## 七、常见问题排查

### 1. apt 报 "Could not get lock ... unattended-upgr"

系统自动更新占用了 dpkg 锁：

```bash
pkill -f unattended-upgr
sleep 3
# 重新执行安装命令
```

### 2. docker-start.sh 报 "TLS 证书未生成"

```bash
cd docker && bash gen_certs.sh <公网IP> && cd ..
```

### 3. 服务起来后发消息报 "Table chatmessage_0 doesn't exist"

分片表没建，手动补：

```bash
docker exec -i mysql-master mysql -uroot -p123456 JerryChat < MySQL/migrate_shard.sql
```

### 4. 检查 MySQL 主从状态

```bash
docker exec mysql-slave mysql -uroot -p123456 -e 'SHOW SLAVE STATUS\G' | grep -E 'Slave_IO_Running|Slave_SQL_Running|Seconds_Behind_Master'
# 期望两个 Yes，Seconds_Behind_Master = 0
```

### 5. 服务启动即崩 / 连不上 MySQL/Redis

```bash
# 看日志定位
tail -f logs/StatusServer.log
tail -f logs/ChatServer1.log

# 确认基础设施容器在跑
docker ps

# 确认裸机配置正确（连的是 127.0.0.1 + 宿主机映射端口，不是容器名）
cat ChatServer1/config.local.ini
```

### 6. 重新部署（改了代码）

```bash
cd IM/linux-server
git pull                              # 拉最新代码
sh build.sh                           # 重新编译
sh start-all.sh                       # 重启服务
```
